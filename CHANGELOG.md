# Changelog

Notable changes to Serena Group Manager are documented here.

## 1.0.0 — Initial project

- Added Telegram Serverless message and callback handlers.
- Added group moderation commands for ban, unban, kick, mute and unmute.
- Added persistent warning history, rules and welcome settings.
- Added purge, pin/unpin, ID, admin list, version and status commands.
- Added Termux and cross-platform deployment documentation.
- Added SDK reference, security policy and automated syntax validation.
